# hedges.txt — hedge lexicon for the D5 hedge-rate feature
#
# Matching is case-insensitive, whitespace-normalised, on word boundaries.
# Multi-word entries are matched as contiguous token sequences.
# Longest match wins; each matched span is counted once.
# hedge_rate = (matched hedge tokens) / (total tokens)
#
# ---------------------------------------------------------------------------
# SOURCES
#
# [H05] Hyland, K. (2005). Metadiscourse: Exploring Interaction in Writing.
#       London: Continuum. Appendix (interactional metadiscourse: hedges).
#       The single most widely reused published hedge list; Hyland's
#       interpersonal model is the dominant framework in metadiscourse work
#       and hedges are its most-studied category.
#
# [H98] Hyland, K. (1998). Hedging in Scientific Research Articles.
#       Amsterdam: John Benjamins. Ch. 5, taxonomy of hedging devices
#       (accuracy-oriented / writer-oriented / reader-oriented).
#
# [HO90] Holmes, J. (1990). Hedges and boosters in women's and men's speech.
#       Language & Communication, 10(3), 185-205.
#       Source for CONVERSATIONAL hedges (pragmatic particles, tag-like
#       softeners) that the academic-register lists above do not cover.
#
# [HO84] Holmes, J. (1984). Modifying illocutionary force.
#       Journal of Pragmatics, 8(3), 345-365. Attenuation devices.
#
# [L73] Lakoff, G. (1973). Hedges: A study in meaning criteria and the logic
#       of fuzzy concepts. Journal of Philosophical Logic, 2(4), 458-508.
#       Origin of the term; approximators / fuzzy-category markers.
#
# [BL87] Brown, P. & Levinson, S. (1987). Politeness: Some Universals in
#       Language Usage. Cambridge UP. Negative-politeness mitigation:
#       apologies, deference forms, minimising expressions.
#
# NOTE ON REGISTER FIT: [H05]/[H98] are drawn from academic prose. This
# corpus is short conversational/AAC utterances, so entries below are the
# intersection of those lists with items attested in conversational hedging
# work [HO84][HO90][BL87]. Section 7 marks the small number of entries that
# are conversational variants not appearing verbatim in any of the above;
# they are flagged so a reviewer can exclude them and re-run.
# ---------------------------------------------------------------------------
